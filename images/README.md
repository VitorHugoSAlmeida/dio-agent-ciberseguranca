# Evidências do laboratório

Este diretório está reservado a capturas **reais**, feitas pelo estudante no VS Code e no Hermes, depois da execução em seu ambiente. As capturas podem mostrar:

1. O agente perguntando sobre **autorização e escopo** antes de sugerir comandos.
2. A análise de `exemplos/app_vulneravel.py` com risco, impacto e correção.
3. A revisão da versão corrigida `exemplos/app.py`.
4. O resultado de `python -m unittest discover -s testes -v`.

Não confundir imagens ilustrativas com evidência de execução. A execução automática pode ser conferida em **Actions → Testes de segurança**.
